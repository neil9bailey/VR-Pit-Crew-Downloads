# VR Pit Crew 0.3.1 — Windows installer preview

The first public installer package for VR Pit Crew, a free Windows companion by Neil9Bailey for Assetto Corsa and Quest VR sim racing.

## Download

- **VR-Pit-Crew-0.3.1-Setup-x64.exe** — recommended Windows installer.
- **VR-Pit-Crew-0.3.1-Windows-x64.zip** — portable version; extract the whole folder.
- **SHA256SUMS.txt** — integrity checksums for both packages.

GitHub's automatic “Source code” ZIP/tar.gz contains only the download repository documentation. It is not the application. The application source remains private.

## Included

- Per-user installation, Start menu shortcuts, optional desktop shortcut and uninstall support.
- Checks for .NET Framework 4.8 and Microsoft Edge WebView2 Runtime before installation.
- Profiles and backups preserved during upgrade/uninstall.
- Prerequisite scan, guided setup, 101 supported tuning controls, preview/apply/backups/Undo, saved profiles, Quest runtime profiles and AC telemetry/application frame capture.
- Discord community and optional PayPal support at https://paypal.me/neil9bailey.

## Requirements and limits

Windows 10/11 x64. Python is bundled. This is an **unsigned preview**, focused on original Assetto Corsa, Quest USB Link and NVIDIA. Windows may show an unknown-publisher warning. There is no universal hardware/FPS guarantee.

Actual Quest ASW/supersampling effects and automation need Meta HUD validation; second-PC and on-track testing remain in progress. PresentMon FPS may measure a desktop mirror and must not be interpreted as headset FPS. Vendor firmware/calibration, headset refresh/render resolution and GPU clocks/fan curves remain vendor-managed.

Save a baseline and review changes before applying. Close the sim and Content Manager before changing their files. Runtime automation is off by default. The application does not automatically upload telemetry or payment data.
